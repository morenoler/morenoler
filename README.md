# Аналитика данных и Python

Начинающий аналитик данных и Python-разработчик. Учусь на направлении «Прикладная информатика» в РТУ МИРЭА. Работаю с Python, SQL, анализом данных и небольшими веб-сервисами.

## Проекты

- **[Продажи и удержание интернет-магазина](https://github.com/morenoler/retail-sales-retention)** — разобрал более миллиона строк Online Retail II. Убрал 22 523 строки пересечения двух листов, посчитал помесячные продажи и возврат покупателей по когортам. [Открыть отчёт](https://morenoler.github.io/retail-sales-retention/).
- **[Продуктовая аналитика Tiny-Cloud](https://github.com/morenoler/tiny-cloud-product-analytics)** — описал события существующего приложения, реализовал запись событий, SQL-метрики и отчёт по воронке и удержанию. В отчёте используются **смоделированные данные**; сбор на рабочем сервере пока не подключён. [Открыть демоотчёт](https://morenoler.github.io/tiny-cloud-product-analytics/).
- **[Классификация рамановских спектров](https://github.com/morenoler/raman-glucose-classification)** — сравнил три базовые модели для определения наличия глюкозы. Разделил выборку по физическим лункам, чтобы повторы не попадали одновременно в обучение и тест; проверил качество при более слабом сигнале. [Открыть отчёт](https://morenoler.github.io/raman-glucose-classification/).

Стек этих проектов: Python, SQL, SQLite, pandas, scikit-learn, визуализация данных. Ищу стажировку или позицию Junior Data Analyst; также интересны задачи автоматизации на Python.
